# Sistem-Parkir-Otomatis

Sistem parkir otomatis menggunakan Arduino, servo, LCD, potensiometer, Motor DC dan LED

# Daftar Pin Utama:
* **Servo (Palang):** Pin 9
* **Push Button:** Pin 2
* **Potensiometer:** Pin A0
* **LCD I2C:** SDA (A4), SCL (A5)
* **Motor DC:** Pin 3
* **LED Merah (Penuh):** Pin 12
* **LED Kuning (Waspada):** Pin 11
* **LED Hijau (Tersedia):** Pin 13
