### 📌 Daftar Komponen dan Konfigurasi Pin

| Nama Komponen | Pin Arduino | Fungsi / Deskripsi |
| :--- | :--- | :--- |
| **Arduino Uno** | - | Mikrokontroler utama (otak sistem) |
| **Servo Motor** | D9 | Penggerak palang pintu otomatis |
| **LCD 16x2 I2C** | A4 (SDA), A5 (SCL) | Menampilkan status dan sisa kuota parkir |
| **Potensiometer** | A0 | Simulasi sensor kapasitas kendaraan |
| **Push Button** | D2 | Tombol pemicu untuk membuka palang |
| **LED Merah** | D12 | Indikator status parkir PENUH |
| **LED Kuning** | D11 | Indikator status parkir WASPADA |
| **LED Hijau** | D13 | Indikator status parkir TERSEDIA |
| **Motor DC** | D3 | Simulasi kipas sirkulasi udara |
